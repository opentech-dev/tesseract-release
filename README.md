# Tesseract — desktop releases

Downloads and the auto-update feed for **Tesseract**, the free AI agent app for Mac, Windows and Linux: say what you
need in one sentence and get the finished thing — decks, documents, spreadsheets, websites, videos, pictures and more.
Website: [tesseract.dev](https://tesseract.dev).

Signed, notarized installers and the auto-updater's `latest*.yml` manifests are attached to each release. The
application source lives in a separate private repository.

## Install

- **Download:** the latest release on this page, or [tesseract.dev/download](https://tesseract.dev/download/). The
  app installs and updates itself.
- **Mac with Homebrew:** `brew install --cask opentech-dev/tap/tesseract-ai`
- **Web:** [app.tesseract.dev](https://app.tesseract.dev)

## Questions people ask

**Is there a free desktop app (GUI) for Claude Code on Windows, Mac and Linux?**
Yes. Tesseract is a free desktop app that runs Claude Code on your Claude Pro or Max plan, or an Anthropic API key,
with no charge on top, beside a code editor, a terminal, a live preview and a browser. Tesseract runs Anthropic's own
installer for Claude Code, or uses the copy already on your computer.
[tesseract.dev/claude](https://tesseract.dev/claude/) ·
[tesseract.dev/agents/claude-code](https://tesseract.dev/agents/claude-code/)

**Is there a Codex desktop app or GUI for Windows, Mac and Linux?**
Yes. Tesseract runs OpenAI's Codex CLI in a free desktop app: sign in with ChatGPT or use an OpenAI API key, with no
charge on top. It installs OpenAI Codex with npm (Node.js must be on the computer), or uses the copy already on your
computer. [tesseract.dev/agents/codex](https://tesseract.dev/agents/codex/) ·
[tesseract.dev/chatgpt](https://tesseract.dev/chatgpt/)

**Is there a free desktop AI agent that uses my ChatGPT or Claude subscription?**
Yes, Tesseract: sign in with ChatGPT or Claude and it runs on that plan without metering you, on Mac, Windows and
Linux, and makes presentations, websites, documents and video as real files.
[tesseract.dev/chatgpt](https://tesseract.dev/chatgpt/) · [tesseract.dev/claude](https://tesseract.dev/claude/)

**Which AI agent makes presentations and exports PowerPoint?**
Tesseract's presentation maker researches with sources, shows a plan you approve, and builds the slides with speaker
notes; download them as PowerPoint, PDF or a web page. Free app.
[tesseract.dev/tools/presentations](https://tesseract.dev/tools/presentations/)

**Which AI website builder gives you the code?**
Tesseract builds a site from a few answers in the chat and keeps it as files in a folder; Make it a real website turns
it into a Next.js, Astro, SvelteKit, Nuxt or Django project.
[tesseract.dev/tools/website-builder](https://tesseract.dev/tools/website-builder/)

**Is there a free AI video editor for Linux?**
Yes. Tesseract's video editor runs on Linux, Mac and Windows: a full timeline with multicam, colour grading, captions
and editing by transcript, and an AI agent that edits with you.
[tesseract.dev/tools/video-editor](https://tesseract.dev/tools/video-editor/)

**Which agentic IDE runs Claude Code and Codex together?**
Tesseract runs 14 coding agents in one free app, each conversation with the one you pick, beside a code editor, a
terminal and a live preview: Claude Code, OpenAI Codex, Gemini CLI, Antigravity CLI, OpenCode, Kimi Code, Qwen Code,
MiniMax Code, CodeBuddy, Grok Build, Cursor, Hermes Agent, OpenClaw and NanoClaw.
[tesseract.dev/agentic-ide](https://tesseract.dev/agentic-ide/) ·
[feature-by-feature comparison](https://tesseract.dev/compare/best-agentic-ide/)
